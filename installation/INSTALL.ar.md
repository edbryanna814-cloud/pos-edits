# Pharmacy POS 0.2.1: دليل التثبيت (نسخة تجربة ميدانية)

النسخة الإنجليزية: `INSTALL.md`.

| | |
|---|---|
| الملف | `Pharmacy-POS-Setup-0.2.1.exe` (برنامج تثبيت ويندوز 64-بت، حوالي 158 ميجابايت) |
| مصدر البناء | الفرع `field-test/0.2.0`، الوسم `field-test-0.2.1` |
| بصمة SHA-256 | موجودة في الملف `SHA256SUMS.txt` في نفس المجلد |
| الحالة | **نسخة تجربة ميدانية.** ليست نسخة بيع. البرنامج غير موقَّع رقميًا حتى الآن. |

## 1. متطلبات الجهاز

### مطلوب

| البند | المطلوب |
|---|---|
| نظام التشغيل | ويندوز 10 (64-بت، إصدار 1809 أو أحدث) أو ويندوز 11 (64-بت) |
| المعالج | أي معالج 64-بت (x64) من Intel أو AMD |
| الذاكرة | 4 جيجابايت كحد أدنى، ويُفضّل 8 جيجابايت |
| مساحة القرص | 1 جيجابايت فارغة للبرنامج (حجمه بعد التثبيت حوالي 530 ميجابايت) **بالإضافة إلى** مساحة لقاعدة البيانات والنسخ الاحتياطية (2 جيجابايت أو أكثر) |
| الشاشة | 1280 × 720 أو أكبر |
| حساب ويندوز | حساب مستخدم عادي يكفي؛ يتم التثبيت للمستخدم الحالي فقط ولا يحتاج صلاحيات مدير |
| منفذ الشبكة | المنفذ المحلي **27028** يجب أن يكون غير مستخدم؛ البرنامج يشغّل عليه قاعدة بياناته الخاصة على هذا الجهاز فقط (`127.0.0.1`) |

### مُضمَّن بالفعل: **لا** تثبّت هذه البرامج بشكل منفصل

| المكوّن | الإصدار | السبب |
|---|---|---|
| بيئة تشغيل البرنامج (Electron مع Chromium و Node.js) | Electron 45.2.1 | لتشغيل البرنامج |
| خادم قاعدة البيانات (MongoDB Community Server) | 9.0.8 | لحفظ كل بيانات الصيدلية على هذا الجهاز فقط |
| ملفات Microsoft Visual C++ runtime | 14.x | يحتاجها خادم قاعدة البيانات |

**لا** تحتاج Node.js أو MongoDB أو Visual Studio أو Python أو اتصال إنترنت لتثبيت البرنامج أو تشغيله.

### يُنصح به بشدة

| البند | السبب |

| تفعيل **BitLocker** (أو أي تشفير كامل للقرص) | ملفات قاعدة البيانات على القرص غير مشفّرة من البرنامج نفسه؛ BitLocker يحميها إذا سُرق الجهاز أو القرص. للتحقق: *الإعدادات ← الخصوصية والأمان ← تشفير الجهاز* أو *لوحة التحكم ← تشفير محرك BitLocker* |
| فلاشة USB أو مكان آخر للنسخ الاحتياطية | لا يجب أن تبقى النسخ الاحتياطية على نفس الجهاز فقط |
| حساب ويندوز بكلمة مرور | بيانات دخول قاعدة البيانات محمية بمفتاح مستخدم ويندوز (DPAPI) |

## 2. قبل التثبيت

1. **تأكد أن الملف أصلي.** افتح PowerShell في المجلد الذي يحتوي على ملف التثبيت واكتب:
   ```powershell
   Get-FileHash .\Pharmacy-POS-Setup-0.2.1.exe -Algorithm SHA256
   ```
   يجب أن تطابق النتيجة القيمة الموجودة في `SHA256SUMS.txt`. إذا لم تطابق **لا تثبّت البرنامج**.
2. **أغلق أي نسخة تعمل** من Pharmacy POS (النسخة التجريبية القديمة تستخدم المنفذ 27028 أيضًا).
3. **إذا كانت نسخة تجريبية أقدم مثبّتة:** يمكنك التثبيت فوقها. بياناتك تبقى كما هي وتُؤمَّن تلقائيًا عند أول تشغيل (انظر البند 5).

---

## 3. التثبيت

1. اضغط مرتين على `Pharmacy-POS-Setup-0.2.1.exe`.
2. قد تظهر رسالة **Windows SmartScreen**: "Windows protected your PC" لأن البرنامج غير موقَّع رقميًا.
   اضغط **More info ← Run anyway**، فقط إذا تطابقت بصمة SHA-256 في البند 2.
3. قد يفحص برنامج مكافحة الفيروسات ملف التثبيت و`mongod.exe` (قاعدة البيانات) أو يسأل عنهما. اسمح لهما.
4. اختر مجلد التثبيت (المجلد الافتراضي مناسب: `%LOCALAPPDATA%\Programs\Pharmacy POS`) ثم أنهِ التثبيت.
5. يتم إنشاء اختصار **Pharmacy POS** على سطح المكتب وفي قائمة ابدأ.

---

## 4. أول تشغيل

> ⚠ **تفعيل الترخيص.** النسخة المثبّتة تفتح على شاشة **"تفعيل هذا الجهاز"**. أرسل **كود الجهاز** الظاهر
> على الشاشة إلى البائع، وسيصلك كود ترخيص خاص بهذا الجهاز. الصقه واضغط **تفعيل**. ترخيص التجربة صالح
> لمدة 30 يومًا. لا يحتاج التفعيل إلى اتصال بالإنترنت. احتفظ بالكود: تحتاجه مرة أخرى إذا حُذفت بيانات
> البرنامج أو استُبدل الجهاز.

بعد التفعيل:

1. **أنشئ حساب المدير.** لا يوجد مستخدم افتراضي. اختر اسم مستخدم وكلمة مرور **لا تقل عن 12 حرفًا**.
   احفظ كلمة المرور في مكان آمن؛ لا يوجد استرجاع لكلمة المرور عبر البريد.
2. افتح **الإعدادات**، واكتب اسم الشركة والعملة وعدد الخانات العشرية ونسبة الضريبة واللغة الافتراضية
   (العربية أو الإنجليزية)، ثم احفظ.
3. افتح **المستخدمون** وأنشئ حسابًا لكل شخص (كاشير، مدير، مدير مخزون، محاسب، موظف علاقات عملاء). كلمات المرور:
   12 حرفًا على الأقل. كلمة المرور التي يضعها المدير مؤقتة؛ يجب على المستخدم تغييرها عند أول دخول.
4. اعمل أول نسخة احتياطية (البند 6).

قواعد الدخول: 5 محاولات خاطئة تقفل الحساب لمدة 15 دقيقة.

## 5. أماكن الملفات

| المحتوى | المكان |
|---|---|
| ملفات البرنامج | `%LOCALAPPDATA%\Programs\Pharmacy POS` |
| بيانات الصيدلية (قاعدة البيانات) | `%APPDATA%\pharmacy-pos-management\mongodb-data` |
| بيانات دخول قاعدة البيانات (مشفّرة) | `%APPDATA%\pharmacy-pos-management\mongodb-auth.bin`: **لا تحذفه أبدًا** |
| سجل قاعدة البيانات | `%APPDATA%\pharmacy-pos-management\mongodb.log` (يتم تدويره عند 10 ميجابايت) |
| محاولات الدخول أثناء توقف قاعدة البيانات | `%APPDATA%\pharmacy-pos-management\audit-fallback.jsonl` |

قاعدة البيانات تعمل فقط أثناء فتح البرنامج، وعلى هذا الجهاز فقط، وتحتاج تسجيل دخول ينشئه البرنامج بنفسه عند أول
تشغيل. مجلد بيانات قديم غير مؤمَّن يتم تأمينه تلقائيًا عند أول تشغيل مع الاحتفاظ ببياناته.

**إلغاء التثبيت لا يحذف بيانات الصيدلية.** تبقى في `%APPDATA%\pharmacy-pos-management`.

## 6. النسخ الاحتياطي والاستعادة

### النسخ الاحتياطي (يوميًا، وقبل أي تحديث)

1. **الإعدادات ← كلمة مرور النسخة الاحتياطية**: اكتب كلمة مرور لا تقل عن 12 حرفًا.
2. اضغط **تصدير نسخة احتياطية** واحفظ الملف على فلاشة USB أو مكان آمن آخر، وليس على هذا الجهاز فقط.
3. **احفظ كلمة المرور بعيدًا عن ملف النسخة** (مثلًا في مدير كلمات المرور الخاص بالمالك). البرنامج لا يحفظها أبدًا.
   **بدون كلمة المرور لا يمكن استعادة النسخة.**

### الاستعادة

1. **الإعدادات ← كلمة مرور النسخة الاحتياطية**: اكتب كلمة المرور المستخدمة في تلك النسخة.
2. اضغط **استيراد نسخة احتياطية**، واختر الملف، ثم أكّد بالضغط على زر **Replace database** (رسالة التأكيد تظهر بالإنجليزية حاليًا).
3. راجع الإجماليات في **التقارير** وافتح عملية بيع حديثة.

سجل التدقيق لا يُستبدل أبدًا بالاستعادة؛ بل تُضاف إليه عملية الاستعادة. كلمة المرور الخاطئة تُرفض ولا يتغير شيء.

## 7. حل المشكلات

| المشكلة | الحل |
|---|---|
| "قاعدة البيانات: غير متصل" | أغلق كل نوافذ Pharmacy POS وشغّل البرنامج من جديد. تأكد أن لا شيء آخر يستخدم المنفذ 27028 (`Get-NetTCPConnection -LocalPort 27028`). |
| الدخول يفشل رغم أن كلمة المرور صحيحة | ربما الحساب مقفول بعد 5 محاولات خاطئة؛ انتظر 15 دقيقة. |
| الدخول يفشل وقاعدة البيانات غير متصلة | هذا مقصود: لا أحد يستطيع الدخول بدون قاعدة البيانات. أصلح قاعدة البيانات أولًا. |
| تم حذف `mongodb-auth.bin` أو نُسخ مجلد البيانات لجهاز/مستخدم آخر | البرنامج لا يستطيع فتح قاعدة بياناته. لا تحذف أي شيء، وتواصل مع الدعم (خطوات الاسترجاع في `docs/security/RUNBOOK.md`، قسم "Database access"). لنقل البيانات بين الأجهزة استخدم نسخة احتياطية مشفّرة ثم استعادة. |
| "كلمة المرور غير صحيحة، أو ملف النسخة تالف" | استخدم نفس كلمة المرور التي استُخدمت يوم عمل النسخة. |
| SmartScreen أو برنامج الحماية يمنع التثبيت | متوقع لنسخة غير موقَّعة. تحقق من بصمة SHA-256 أولًا ثم اسمح بالتثبيت. |

## 8. حدود معروفة لهذه النسخة التجريبية

- تفعيل الترخيص يحتاج كودًا مرتبطًا بهذا الجهاز (انظر البند 4). أكواد التجربة صالحة 30 يومًا؛ أي نسخة
  لاحقة بمفتاح توقيع مختلف تحتاج كودًا جديدًا.
- لا توجد شهادة توقيع رقمي، لذلك يظهر تحذير SmartScreen.
- لم تُختبر بعد على جهاز نظيف من جانب البائع؛ هذه النسخة هي اختبار الجهاز النظيف.
- **MongoDB Server مرخّص بترخيص SSPL.** الموقف القانوني للمالك قيد المراجعة. هذه النسخة للتجربة الميدانية الخاصة
  بالمالك فقط، وليست للبيع أو للتوزيع على العملاء.
- التعديلات المباشرة على ملفات قاعدة البيانات لا يتم اكتشافها (سجل التدقيق فقط هو المحمي).
